# Movie Review Hub

## Project Description

**Movie Review Hub** is a website where users can
discover movies, read reviews, and rate their favorites.

## Planned Features

- Browse a collection of movies
- Rate movies from 1 to 5 stars
- Read and submit movie reviews
- View recommended movies

## Technologies

- **Node.js** for JavaScript execution
- **Express.js** for the future web server
- **HTML/CSS** for website design
- **JavaScript** for interactive features

## How to Run

Install dependencies:

```bash
npm install
```

Run the starter application:

```bash
npm run script
```

## Current Functionality

The starter application displays a welcome message
and uses a movie-rating function to print a review.
